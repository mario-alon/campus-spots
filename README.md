# Campus Spots

A small pocket guide to Kraków for students. It will show a list of places worth visiting, the weather at each of them right now, your favourites, and spots you add yourself with a photo from your camera and your GPS position.

## Getting Started

To run the project locally, install the dependencies and start the development server:

npm install

npx expo start

Scan the generated QR code using the Expo Go application on iOS or Android.
